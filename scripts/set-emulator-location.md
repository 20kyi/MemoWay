# 안드로이드 에뮬레이터 위치 설정 가이드

## 방법 1: Extended Controls 사용 (가장 쉬움)

1. 에뮬레이터 실행 중
2. 에뮬레이터 창 우측의 `...` (More) 버튼 클릭
3. **Location** 탭 선택
4. 좌표 입력 후 **Set location** 클릭

### 주요 한국 도시 좌표

- **서울 (시청)**: 위도 `37.5665`, 경도 `126.9780`
- **서울 (강남)**: 위도 `37.4979`, 경도 `127.0276`
- **부산**: 위도 `35.1796`, 경도 `129.0756`
- **인천**: 위도 `37.4563`, 경도 `126.7052`
- **대구**: 위도 `35.8714`, 경도 `128.6014`
- **광주**: 위도 `35.1595`, 경도 `126.8526`
- **대전**: 위도 `36.3504`, 경도 `127.3845`

## 방법 2: 지도에서 위치 선택

1. Extended Controls → Location 탭
2. 지도에서 원하는 위치 클릭
3. **Set location** 클릭

## 방법 3: ADB 명령어 사용

터미널/명령 프롬프트에서:

```bash
# 서울 시청 위치로 설정
adb emu geo fix 126.9780 37.5665

# 부산 위치로 설정
adb emu geo fix 129.0756 35.1796

# 사용자 지정 위치
adb emu geo fix <경도> <위도>
```

**참고**: 
- 경도(Longitude)가 먼저, 위도(Latitude)가 나중
- 경도: 동경은 양수, 서경은 음수
- 위도: 북위는 양수, 남위는 음수

## 방법 4: 실시간 위치 시뮬레이션

Extended Controls → Location 탭에서:
- **Single points**: 한 번에 하나의 위치 설정
- **Route playback**: 경로 재생 (GPX 파일 필요)
- **Route**: 여러 지점을 경로로 설정

## 현재 위치 확인

앱에서 현재 위치를 확인하려면:
1. 앱 실행
2. 지도 화면에서 내 위치 버튼 클릭
3. 또는 앱이 자동으로 현재 위치로 이동

## 문제 해결

### 위치가 업데이트되지 않는 경우:
1. 에뮬레이터 재시작
2. 앱 재시작
3. GPS 권한 확인 (앱 설정에서)

### 정확한 위치를 찾으려면:
- Google Maps에서 원하는 위치 검색
- 우클릭 → "이곳이 궁금한가요?" 클릭
- 좌표 복사 (예: `37.5665, 126.9780`)
